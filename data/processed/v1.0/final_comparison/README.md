# V1.0 色卡最终对比结果

优先打开：

1. `V1.0_色卡最终对比表.xlsx`：所有色卡曲线在一个 Excel 文件里，包含曲线表、差异指标和图表。
2. `V1.0_色卡最终对比图_平滑归一化.png`：所有色卡平滑归一化曲线叠加图。
3. `V1.0_色卡最终对比图_参考校正相对反射.png`：所有色卡参考校正相对反射曲线叠加图。

CSV：

- `V1.0_色卡组均值曲线_同表_平滑归一化.csv`：Pixel + 每个色卡一列，适合看谱形差异。
- `V1.0_色卡组均值曲线_同表_参考校正.csv`：Pixel + 每个色卡一列，适合看参考校正后的相对反射差异。
- `V1.0_色卡曲线差异指标.csv`：峰值、面积、高低像素段比值等摘要指标。
