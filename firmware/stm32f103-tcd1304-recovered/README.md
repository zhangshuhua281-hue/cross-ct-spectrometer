# STM32F103C8T6 采集固件恢复源码说明

这个目录是根据当前实物单片机 Flash 导出的 `tcd1304_mcu_flash_64k.bin/.hex` 反汇编后整理的源码包。

它不是原作者的原始工程源码。HEX/BIN 里没有变量名、注释、C 文件结构和 Keil 工程分组信息，所以这里整理的是“等价逻辑恢复版”，用于理解、继续移植和后续修改。

## 文件

- `src/tcd1304_firmware_recovered.c`
  - 采集固件主逻辑恢复版。
  - 包含串口命令处理、积分时间表、12 位/8 位数据发送、摘要帧发送、DMA 完成中断逻辑。
- `docs/protocol.md`
  - 上位机与单片机串口协议。
- `docs/recovery_notes.md`
  - 恢复依据、已确认硬件、未完全还原部分。

## 已确认功能

- 串口：USART1，`921600 8N1`
- 采集命令：
  - `0xA1`：发送 3648 点 12 位数据，低字节在前，共 7296 字节。
  - `0xA2`：发送 3648 点 8 位数据，共 3648 字节。
  - `0xA3`：发送摘要帧，帧头 `0xFE`，共 12 字节。
- 积分时间命令：
  - `0xB1` 到 `0xD8`
  - 对应 `10 us` 到 `3 s`

## 重要边界

当前目录里的源码适合继续开发和移植，但不能保证直接编译后得到和实物导出固件逐字节相同的 HEX。

如果要在源码层继续改单片机逻辑，建议以 `src/tcd1304_firmware_recovered.c` 为依据，把 `board_*` 底层函数移植到 Keil 标准外设库工程中，然后用示波器确认 TCD1304 的 MCLK、SH、ICG 等时序。
