# 串口协议与积分时间表

## 串口参数

- 外设：USART1
- 波特率：921600
- 数据位：8
- 校验：无
- 停止位：1

## 上位机命令

| 命令 | 功能 | 单片机返回 |
|---:|---|---|
| `0xA1` | 读取完整 12 位数据 | 3648 点，每点 2 字节，低字节在前，共 7296 字节 |
| `0xA2` | 读取完整 8 位数据 | 3648 点，每点 1 字节，共 3648 字节 |
| `0xA3` | 读取摘要数据 | 12 字节，首字节 `0xFE` |
| `0xB1`-`0xD8` | 设置积分时间 | 不返回数据，单片机重启采集时序 |

## `0xA3` 摘要帧

格式：

```text
FE
max_pos_high100 max_pos_low100
min_pos_high100 min_pos_low100
average_high100 average_low100
max_value_high100 max_value_low100
min_value_high100 min_value_low100
checksum
```

其中 `high100 = value / 100`，`low100 = value % 100`。

`checksum` 是前面 5 个数拆成 base-100 后 10 个字节的累加低 8 位。
