# Open Source Notes

整理时保留了能帮助复现和验证的资料，排除了更适合发布到 GitHub Releases 或不适合公开再分发的文件。

## Kept

- 光学设计文件、PCB 原理图和 PCB 工程压缩包。
- 结构 STEP 文件。
- STM32G431、ESP32-S3 和 STM32F103 恢复版固件资料。
- V1.0/V2.0/V3.0 原始采集数据。
- V1.0/V3.0 处理后的 CSV、SVG、PNG 和脚本。
- 项目报告 PDF。

## Excluded

- 编译输出和本地工程临时文件。
- 预编译 Windows 上位机 EXE。
- MATLAB `.fig` 二进制图。
- 参赛视频、PPT、DOCX。
- 参考文献 PDF。

## Before publishing

发布到 GitHub 前建议人工检查一次 `docs/project-report/project-report.pdf`，确认其中没有不想公开的姓名、学校、联系方式、比赛账号或未授权图片。
